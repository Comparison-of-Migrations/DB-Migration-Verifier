# 비교 화면 증거

`baseline.jpg`와 `baseline-dom.txt`는 규칙 설정 시 실제 원본 웹의 한국어 연결 페이지다. 1138×1097 CSS px, DPR 2, PostgreSQL 선택, 미접속 예시 상태. [환경](../source/manifest.json), [SVG 관측](../source/svg-icon-baseline.json).

이 원본 한 장은 native 일치 증거가 아니다. 컴포넌트 작업 시 `<component>-<state>-web/native` 쌍으로 보관하고 해당 명세에 창 내부 크기·OS/배율·언어·데이터 상태·차이를 연결한다. 상태·동작은 필요한 전후 화면과 관찰 기록으로 검증한다. 실제 비밀번호·개인 데이터 캡처 금지.
