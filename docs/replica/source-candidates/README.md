# 복제 기준에서 제외한 후보

`w01-unapproved.html.txt`: 새 복제 규칙이 제시되기 직전 파일에만 있던 웹 동작 보강 초안. 실제 로드된 웹과 style/script가 달랐으며 저장/재열기 연결 검증도 끝나지 않았다. 복제 Source of Truth가 아니다. 미검증 후보를 나중에 원본으로 오인하지 않도록 보존한다.

현재 웹 파일은 실행 중인 원본의 inline style/script로 맞췄다. [원본 캡처/해시](../source/manifest.json). 이 후보를 서버 파일로 되돌리거나 복제 기준으로 자동 채택하지 않는다.
