DB-Migration-Verifier
마이그레이션 결과를 비교하세요
옮긴 뒤의 두 DB를 비교하고, 확인한 범위까지 분명하게.
마이그레이션을 마친 개발자가 논문의 다축 검증 방법으로 두 DB의 데이터·구조·권한·객체를 비교하고, 차이와 확인하지 못한 영역을 찾도록 돕습니다.
저장한 결과 JSON은 DB 연결이나 새 검사 없이 바로 열어 확인할 수 있습니다.
접속 후 앱이 조회 가능한 범위와 필요한 준비를 안내합니다.
