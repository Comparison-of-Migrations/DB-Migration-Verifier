# macOS 앱 실행 파일 복구 · 2026-10-09

사용자가 프로그램이 표시되지 않는다고 알려 현재 실행 파일을 확인했다. 저장공간 정리에서 생성된 실행 묶음이 제거된 상태였고, 시스템 .NET SDK 10.0.401과 소스는 남아 있었다.

- 기존 `tools/package-macos.sh`로 macOS arm64 실행 묶음 하나를 다시 생성했다. publish 종료 코드 0이며 제품 코드는 변경하지 않았다.
- 경로: `artifacts/dev/DB-Migration-Verifier.app`, 크기 119 MiB (`du -sh`). 정식 서명·공증 배포물은 아니다.
- `open artifacts/dev/DB-Migration-Verifier.app --args --replica-preview`로 웹 복제 예시 화면을 열고 Finder에서 앱 위치를 표시했다.
- 실제 macOS 접근성 상태에서 앱 창, 첫 화면 제목, 새 검사 시작·검사 결과 파일로 보기·예시 결과 보기 버튼, 실제 DB 연결 없음 안내를 확인했다.
- 사용자가 사용할 앱 창이므로 열어 두었다. 검증 전용 컴포넌트 창을 만든 것은 아니다.
- 삭제한 Windows VM과 과거 검증 실행 묶음은 복구하지 않았다. 이번 실행 확인은 과거 전체 검증을 다시 수행했다는 의미가 아니다.

기본 더블클릭은 현재 실제 DB 첫 실행판을 열며, 위 인자를 사용하면 웹 복제 예시 화면을 연다. 두 경로는 현재 README에 구분되어 있다. 패키지 복원으로 개발 의존성 캐시가 일부 다시 생성되었으므로 이전 정리 시점의 저장공간 측정치는 현재 측정치가 아니다.
